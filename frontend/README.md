ReportDesk Frontend

This folder contains a React app. To run:

1. npm install
2. npm start

A minimal app will be added later with routes for Dashboard, Login, Reports.

Notes

This is a minimal skeleton. To run the dev server:

```powershell
cd frontend
npm install
npm start
```

The frontend expects the backend to be available at the same host under `/api/*` paths during development (you can use a proxy in `package.json` or configure CORS on the backend).
